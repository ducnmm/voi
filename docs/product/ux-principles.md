# UX Principles

Voi should be minimal, calm, and functional. The interface should feel polished without becoming decorative.

## Product Feel

- Fast.
- Quiet.
- Clear.
- Social but not noisy.
- Premium without looking corporate.

## Interaction Principles

- The primary action should always be obvious.
- Session status should be readable at a glance.
- Avoid long forms during session creation.
- Prefer progressive disclosure over dense settings screens.
- Use familiar web patterns: modals/sheets, segmented toggles, lists, keyboard-friendly forms, and concise navigation. Keep the layout responsive and comfortable on a phone browser.
- Keep player actions lightweight.

## Visual Principles

- Prioritize typography, spacing, and hierarchy.
- Use restrained color with clear semantic states.
- Avoid decorative gradients and generic sports imagery.
- Use icons only when they make actions easier to scan.
- Make player, court, and RSVP states visually distinct.

## Key UI Surfaces

### Home

Shows upcoming sessions and the groups the user cares about.

### Session Page

The most important screen. It should show:

- Date and time.
- Venue.
- Capacity.
- RSVP status.
- Confirmed players.
- Waitlist.
- Court lineup.
- Estimated cost.

### Create Session

Should be short enough to complete quickly:

- Date and time.
- Venue.
- Court count.
- Capacity.
- Fee estimate.
- Skill level.
- Visibility.

### Lineup Board

The signature badminton surface. It should make the session feel organized immediately:

- Court 1, Court 2, Court 3.
- Four slots per court by default.
- Waitlist below confirmed players.
- Clear host controls for moving players.
