# MVP Roadmap

## Milestone 0: Product Spec

Goal: make the MVP clear enough to build.

- Product vision.
- MVP scope.
- UX principles.
- Domain model.
- Feature specs.
- Roadmap.

Exit criteria:

- The MVP has clear non-goals.
- Each feature has acceptance criteria.
- Open product questions are visible.

## Milestone 1: App Skeleton

Goal: create the iOS foundation.

- SwiftUI project and navigation structure.
- iOS design tokens and mock data.
- iOS home, group detail, and session detail screens.

Exit criteria:

- The iOS app can show realistic sample sessions without a backend.
- Core iOS screens feel directionally correct.

## Milestone 2: Session Creation and Groups

Goal: hosts can create reusable groups and sessions.

- Group creation.
- Session creation.
- Session detail.
- Invite link placeholder.

Exit criteria:

- A host can create a session from the app and see it on the home screen.

## Milestone 3: RSVP and Waitlist

Goal: players can join sessions and capacity is enforced.

- Join, Maybe, Can't Go.
- Capacity logic.
- Waitlist.
- Promotion.

Exit criteria:

- Session attendance can be managed without a chat thread.

## Milestone 4: Lineup Board

Goal: badminton-specific organization becomes visible.

- Court board.
- Player assignment.
- Waitlist display.
- Host edit controls.

Exit criteria:

- A host can organize players across courts.

## Milestone 5: Cost Split and Reminders

Goal: reduce the remaining host admin work.

- Cost summary.
- Paid/unpaid tracking.
- Reminder notifications.
- Cancellation and change notifications.

Exit criteria:

- The app covers the main weekly coordination loop.

## Milestone 6: Private Beta

Goal: test with real badminton groups.

- Onboarding polish.
- Error handling.
- Basic analytics.
- Manual feedback loop.
- TestFlight distribution for the iOS app.

Exit criteria:

- At least three real groups use the app for recurring sessions.
